# Chess piece artwork

The SVG files in this folder (`wK.svg` … `bP.svg`) are the "cburnett" chess pieces.

- Author: Colin M.L. Burnett ([User:Cburnett](https://commons.wikimedia.org/wiki/User:Cburnett))
- Licence: [Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)](https://creativecommons.org/licenses/by-sa/3.0/)
- Source: Wikimedia Commons, files `Chess_{k,q,r,b,n,p}{l,d}t45.svg`, e.g.
  <https://commons.wikimedia.org/wiki/File:Chess_klt45.svg>

Changes: files renamed to `<colour><piece>.svg` (`w`/`b` + `K Q R B N P`) and a
`viewBox="0 0 45 45"` attribute added to the root `<svg>` element so the images scale.
